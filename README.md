
# Big data Жолы

### Үлкен деректер (Big Data) дегеніміз не және неліктен оны үйрену керек?

Қазіргі заман ақпараттың заман. Күніне бір адамның өзі ақпарат әлеміне жаңа деректер енгізеді. Оны жүріс тұрысын; қараған видео, кескініні; тұтынған өнімі тағысынтағы Бәрі Бәрі әртүрлі деректер ұяшығында (Database) сақталуда. 

Үлкен компаниялар (Meta, Google, Micrisoft, Қазақстандағы компанияларда) деректерді маңызды актив ретінде таниды және оларды жинауға, сақтауға және талдауға қомақты қаражат салуға дайын.

Бір карапайым супермаркет алып қарасақ. Ол сұраныстарды зерттей келе қай уақытта, қай өнімді, қанша көлемде алу керек екенін анықтай келе табысын арттырады. Өзінің клиенттер базасын қалыптастырып, тұрақты сатыпалушыларының санын арттырады.

Корыта келе айтқанда ақпараттың маңыздылығы күннен күнге арытуы және ақпараттың көлемі еселеп өсуі, Үлкен деректер (Big data) маманына деген сұранысты арттыруда.

Үлкен дерек деп аталуы үшін 4 қасиетті орындалу керек:

    1. Үлкен көлемді (Volume)
    2. Жоғары жылдамдыққа ие (Velocity)
    3. Деректердің әр түрлілігі (Variety)
    4. Деректің сенімділігі (Veracity)

Неліктен үлкен деректерді үйрену керек?

1. Жоғары сұраныс: Үлкен деректер мамандарына бүгінгі күні үлкен сұраныс бар. Компаниялар өз деректерін талдау және олардан пайдалы ақпарат алу үшін білікті мамандарға мұқтаж.
2. Жоғары жалақы: Үлкен деректер саласындағы мамандардың жалақысы өте жоғары. Бұл сала жақсы табыс табуға мүмкіндік береді.
3. Қызықты жұмыс: Үлкен деректермен жұмыс істеу өте қызықты және күрделі процесс. Сіз үнемі жаңа нәрселерді үйреніп, дағдыларыңызды жетілдіріп отырасыз.
4. Үлкен мүмкіндіктер: Үлкен деректер саласы сізге көптеген мүмкіндіктер ашады. Сіз ірі компанияларда, стартаптарда немесе ғылыми-зерттеу институттарында жұмыс істей аласыз.
